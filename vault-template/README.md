# fam-vault — Funding Affiliate Manager memory

Open this folder in Obsidian. Everything the agent does lands here:

- **Daily/** — one note per day: sweep results, approvals, what went out, replies, deals.
- **Affiliates/** — one note per affiliate: source, lifecycle, and a timeline of every touch, reply, and follow-up.
- **Campaigns/**, **Newsletters/**, **Events/**, **Reports/** — drafts and final copy.

The CRM (GoHighLevel) is the system of record for contacts; this vault is the agent's memory and your audit trail.
